# FAQ-бот на 5 вопросов

Небольшой терминальный бот для репетиции: он отвечает на пять заранее известных вопросов о времени, команде, треке, сдаче и призах. Вопрос ищется по ключевым словам; если подходящего совпадения нет, бот отвечает `Не знаю`. Внешние библиотеки не нужны.

## Запуск

Нужен Python 3.10+:

```bash
python3 faq_bot.py
```

Введите вопрос после приглашения `> `. Для завершения напишите `выход` (или нажмите Ctrl+D). Например, на вопрос «Во сколько встречаемся?» бот ответит временем репетиции.

## Проверка

Запуск тестов:

```bash
python3 -m unittest -v
```

FAQ редактируется в `faq.txt`: каждая пара состоит из строк `Q:` и `A:`.
